For your HTML/CSS only project, you need to create a:

Simple chart HTML-CSS only page.
Create a page with a hard-coded chart of your choice, and add a few <p> paragraphs explaining what that chart is about.
Add a div with a Legend for your chart (div with plain text). If you need to show colors in the Legend, use <div>s that you color using CSS, followed by plain text.

For the chart itself, please use svg html element, like in this example:

<svg class="chart" viewBox="0 0 100 100" xmlns="http://www.w3.org/2000/svg">
    <polygon class="chart__area" points="..." />
    <polyline class="chart__line" points="..." />
    <circle class="chart__circle" cx="..." cy="..." r="..." />
    ...
    <circle class="chart__circle" cx="..." cy="..." r="..." />
    <text class="chart__text" x="75" y="0">#</text>
</svg>

or full tutorial:  https://www.w3schools.com/graphics/svg_intro.asp
